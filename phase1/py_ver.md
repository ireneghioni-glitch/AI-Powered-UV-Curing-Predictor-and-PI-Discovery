## 🎯 Why did I choose Python 3.9?
Maximum compatibility: RDKit, OpenCV, TensorFlow/Keras, PyTorch, XGBoost, Reflex… they all work perfectly on Python 3.9.

Proven stability: It is an LTS (Long-Term Support) version that is still widely used in the scientific community.

No surprises: You avoid compatibility issues with libraries that might not yet support Python 3.12 or 3.13.
