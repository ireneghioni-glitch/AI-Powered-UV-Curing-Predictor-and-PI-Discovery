### Explanation of choices

| Monomer | Rationale |
|----------|-------------|
| TMPTA | Tri‑functional: represents monomers that form dense networks (high conversion). |
| DEGDA / HDDA | Di‑functional: represents monomers that form less dense networks. |
| PEGDA | Hydrophilic di‑functional: useful for testing the effect of aqueous solvent. |
| HEMA | Polar mono‑functional: represents hydrophilic monomers with low cross-linking. |
| MMA / Butyl acrylate | Classic mono‑functionals: comparison between methacrylate (slow) and acrylate (fast). |
| Acrylic acid | Acidic monomer: tests the effect of extreme polarity. |
| Styrene | Aromatic monomer: represents a different polymerization family. |
| IBOA | Bulky monomer: tests the steric effect on conversion. |
