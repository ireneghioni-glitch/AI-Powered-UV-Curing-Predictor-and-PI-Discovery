## CO-INITIATORS / SYNERGISTS FOR TYPE II PHOTOINITIATORS
### 1. TERTIARY AMINES (Aliphatic Amines)
The most widely used co-initiators for benzophenone- and thioxanthone-based systems.

| Chemical Name (PubChem search) | Common Trade Name / Abbreviation |
| --- | --- |
| Triethylamine | TEA |
| Triethanolamine | TEOA |
| N-Methyldiethanolamine | MDEA | 
| 2-Dimethylaminoethanol | DMAE |
| N,N-Dimethylbenzylamine | DMBA |
| N-Phenyldiethanolamine | PDEA |
| Diisopropylethylamine | DIPEA |
| 1,4-Diazabicyclo[2.2.2]octane | DABCO (less common) |

### 2. AROMATIC AMINE ESTERS (Highly reactive, very common in coatings)
The highest-performing ones, since their absorption is shifted towards the UV-A range and they generate highly reactive radicals.

| Chemical Name (PubChem search) | Common Trade Name / Abbreviation |
| --- | --- |
|Ethyl 4-(dimethylamino)benzoate | EDB (Ethyl-4-Dimethylaminobenzoate) |
| 2-Ethylhexyl 4-(dimethylamino)benzoate | EHA (Octyl-4-Dimethylaminobenzoate) |
| Methyl 4-(dimethylamino)benzoate | MDB |
| Butyl 4-(dimethylamino)benzoate | BDB |
| 4-(Dimethylamino)benzoic acid | DMABA (acid, less used) |
| Dimethylaminobenzaldehyde | DMAB (used as sensitizer in some reactions) |

### 3. THIOLS / MERCAPTANS (Hydrogen Donors)
Widely used in "thiol-ene" systems or as co-initiators for Type II photoinitiators (especially with camphorquinone).

| Chemical Name (PubChem search) | Common Trade Name / Abbreviation |
| --- | --- |
| 2-Mercaptoethanol | Thioglycol, ME |
| Thioglycolic acid	| Mercaptoacetic acid |
| Ethyl thioglycolate | -- |
| Pentaerythritol tetrakis(3-mercaptopropionate) | PETMP (multifunctional) |
| Trimethylolpropane tris(3-mercaptopropionate) | TMPMP |
| 1,6-Hexanedithiol | HDT |

### 4. OTHER SYNERGISTS / SENSITIZERS (Energy Transfer)
Sometimes the co-initiator acts as a sensitizer (transferring energy to the photoinitiator), but the most common ones are already included in the Type II category (thioxanthones and benzophenones). However, there are specific molecules used as sensitizers for iodonium or sulfonium systems.

| Chemical Name (PubChem search) | Common Trade Name / Abbreviation |
| --- | --- |
| 2-Isopropylthioxanthone | ITX (it's a Type II, but also used as a sensitizer for others)
| Anthracene | Anthracene (used in some special systems) |
| Perylene | Perylene (sensitizer for cationic systems) |
